## 🚆 Featured Project

### Rail Bharat — Railway Reservation Platform

A full-stack railway reservation application built with **Java 21, Spring Boot, Hibernate/JPA, MySQL and JavaScript**.

**Key Features**
- 🔍 Train search by station name/code
- 👤 User registration & login
- 🔐 JWT authentication
- 🎟️ Ticket booking & cancellation
- 🔎 PNR lookup
- 💳 Razorpay Test Mode payment
- 📧 Email notifications
- 💺 Seat availability & fare management
- ☁️ Cloud deployment

🌐 **Live Demo:** https://rail-bharat.vercel.app
